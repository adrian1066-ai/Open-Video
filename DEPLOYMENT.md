# Deploy OpenVideo V6.5

1. Run `SUPABASE_V6_5_VIEW_RULE.sql` in Supabase SQL Editor.
2. Upload these four website files to GitHub:
   - index.html
   - README.md
   - FEATURES.md
   - DEPLOYMENT.md
3. Commit directly to `main`.
4. Wait for GitHub Pages.
5. Test Creator Studio -> Content.
6. Test a signed-out playback from another device/private window.
